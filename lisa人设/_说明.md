本角色的素材边界（推理与写作时必须先看）
----------------------------------------
1. **没有卡面剧情**：没有卡面 ID、没有卡面图；日文原文**只有活动 333／342** 这一批。
   - 语录库只有这两个活动的条目可能带中日对照栏，其余一律「无日文对照」；
   - 语体结论以国服中文译文的用词为底，只有 333／342 的句末形式（だもん / って話だけどね）
     能用日文原句核验，其余日文句末（わ / かしら / のね / てちょうだい）不做断言。
2. **没有主线成文叙述**：百科「经历」为空。全部成长线索来自活动对白，故时间轴是**重建**而非摘录。
3. **活动是 Roselia 全队视角**：莉莎在多数活动里是配角/照顾者/参谋，只有 322《Re:Like Re:Live》
   是她个人向活动。她的台词量分布不均（291/301/314 三个活动里近乎退场，共 8 个单话文件零台词）。
4. **「无中生弟」吃书**：百科第 46、72–74 行记载 2019-10「Do It Ourselves!!」活动里她提到给「弟弟」
   织围巾；官方 2019-10-21 公告修改该设定，此后剧情不再提及。**不得当正史使用**，
   卡片已把它登记为设定废止项。
5. **活动元信息里的年龄不可用**：每个活动 `_活动信息.txt` 都把莉莎写作「今井 莉莎(23)」，
   这是设定年龄占位值，不是剧情内时点；`开催` 写的是**国服日期**（比日服晚 7–9 个月）。
   分期一律用**事件 ID**（与日服首发同序）。

分期口径（用户 2026-02 拍板）
----------------------------
**学校轴两档：高中期 / 大学期**（另设「通用」表示与时期无关的基线）。
- 高中期 ＝ 事件 ID 105–214。依据：156 第4话晴海「你们的演奏的层次感和乐曲的世界观都让人无法想象这是一支高中生乐队」、204 第2话纱夜「感觉这个地方不是我们这种高中生能来的」（均为现在时）。
- 大学期 ＝ 221 起。依据：221 第1话「我在大学校园里偶尔也会看到有女生穿这家的衣服」、243 第4话「毕竟我们已经是大学生了」、273 第4话「和高中时相比，机会没那么多了」「还是有校服的高中时期比较省心」、322 第4话「进了大学之后，周围做美甲的女孩子变多了」。
- 素材里**没有「毕业」字样**，四处证据都指向 322 时她仍在大学在读，故**不设「职业期」**。
- 细则见 `人设工具\配置\lisa.json` 的 `说明_时期`。

重跑方式
--------
在工作区根目录执行（13 步，顺序不能乱）：

    $n = "C:\Users\lqbbe\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe"
    foreach ($s in 'build_index','build_event_index','align_quotes','bulk_extract_quotes','merge_quotes',
                   'render_quotes','sync_card_quotes','render_card','build_writecard','render_writecard',
                   'render_citation_index','verify_quotes','qa_card') {
      & $n "人设工具\$s.mjs" --角色=lisa
    }

`build_event_index.mjs` 只依赖 `roselia剧情\`，与角色无关；其余 12 步按 `配置\lisa.json` 走。
QA 报告落在 `人设工具\qa_report_lisa.json`，语录回检落在 `人设工具\verify_quotes_lisa.json`。

数据说明 / 已知缺口
-------------------
1. 活动 333《ディープ・ローズ・ホライズン》、342《未来想送曲》国服未本地化，但**已补日文原文**
   （7 话齐全，落盘在 `roselia剧情\<活动目录>\` 与 `roselia剧情\_汇总_事件日文.txt`，
   汇总行号可直接引用）。莉莎在这两个活动里分别是开场吐槽位与燐子的第一商量对象，
   卡片据此新增 `语言:"jp"` 证据；因无官方简体中文，这两个活动**不进**中文语录库。
   资源包名分别为 `deeprose_horizon` / `mirai_sousoukyoku`。
2. `roselia剧情\_抓取脚本.mjs` 原先只请求国服 `cn` 资源，取到日文时主动丢弃；本次已把
   333／342 的日文正文单独落盘（`build_event_index.mjs` 现按正文头区分 `正文语言`），
   其余活动不受影响。
3. `_汇总_事件中文.txt` 的合并件偶有单话文件里不存在的段落（如 `_汇总_170…txt:421` 的纱夜台词），
   **引用一律以单话文件为权威口径**，合并件只用于快速回查。
4. 部分活动的出席者名单与文本不一致（如 284 第5话出现插入行 `鸫：是、是这样啊`，而该活动
   参与人只有 Roselia 5 人），写作时不要据此让无关角色出场。
