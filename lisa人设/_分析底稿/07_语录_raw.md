# 07 语录库 raw（今井莉莎）

## 使用说明

- **速查方式**：先看「分类索引」定位分类，再在该分类下按 `Q编号` 取用。每条都是固定字段块：中文／日文／出处／标签／分级／可复用场景。
- **中文为逐字抄录**，不改写、不润色。全角引号、『』、《》、省略号、语气助词一律保留；原文跨行的续行已拼成完整一句。
- **本文件已做机器回检**：全部「中文」字段均对 `roselia剧情\_汇总_事件中文.txt` 与 `roselia剧情\{活动ID}_{活动名}\*` 做过「去空白/去换行后逐字包含」比对，命中 53/53（100%），不一致 0 条。
- **无日文对照**：本角色素材只有国服官方简体中文（事件剧情），不存在日文原文，故每条「日文」字段一律写 `无日文对照`。
- **事件剧情为全队活动**：本角色没有自己的卡面剧情，全部条目来自 Roselia 活动剧情。
- **时期标签**（每条标签中必带其一，学校轴两档 + 通用）：#高中期 ＝ 羽丘女子学园时期（事件 ID 105–214；硬证据：156 第4话晴海「无法想象这是一支高中生乐队」、204 第2话纱夜「不是我们这种高中生能来的」均为现在时）；#大学期 ＝ 四叶女子大学时期（事件 ID ≥ 221；硬证据：221 第1话「我在大学校园里」、243 第4话「毕竟我们已经是大学生了」、322 第4话「进了大学之后…」，且 273 第4话「和高中时相比」确认高中已结束）。**素材里无「毕业」字样、四处证据都指向 322 仍大学在读，故不设「职业期」。分期以事件 ID 为主序（与日服首发同序），不要用素材里写的国服日期或「23 岁」这类设定年龄。**
- **出处格式**：`活动ID 105《Noble・Rose -歌至顶点-》【第1话】序章《寻求的声音》`（活动名与话名与源文件分节头一致）。
