# 07 语录库 raw（凑友希那）

## 使用说明

- **速查方式**：先看「分类索引」定位分类，再在该分类下按 `Q编号` 取用。每条都是固定字段块：中文／日文／出处／标签／分级／可复用场景。
- **中文与日文均为逐字抄录**，不改写、不润色、不自行翻译。全角引号、『』、《》、省略号、语气助词一律保留；原文跨行的续行已拼成完整一句。
- **本文件已做机器回检**：全部「中文」「日文」字段均对 `ykn人设/卡面剧情/_汇总_中文.txt`、`_汇总_日文原文.txt`、`ykn人设/百科资料.txt` 做过「去空白后逐字包含」比对（源文件存在换行续行，比对时允许跨行匹配），**不一致 0 条**。凡源文件中找不到逐字对应者一律放弃，未采用任何改写或自行翻译的版本。
- **源文件混排说明**：`_汇总_中文.txt` 主体为官方简体中文，但其中 **卡面 2536《誰も知らない私》** 与 **卡面 2492《激闘！　真夏の決戦！》** 两篇实际填入的是**日文原文**；这两篇的简体中文在源文件中不存在，故本文件未从这两篇取条目，以免出现「中文栏其实是日文」的假对照。
- **日文缺失说明**：`_汇总_日文原文.txt` 共 49 篇、`_汇总_中文.txt` 共 51 篇；差集为卡面 **10028（小豆泥与蔷薇，2 篇）** 与 **1629【第1篇】（在那之后的相册）**。本文件对这三篇未收录条目，故当前**无「无日文对照」条目**；后续若要补小豆泥篇，请在该篇条目上标「无日文对照」。
- **分级含义**：`[原文]` ＝ 出自上述源文件的原文语句，逐字对应；`[玩梗]` ＝ live 幕间、中之人、PICO、二设等非剧情原文素材（本文件 0 条，可另开小节追加）。
- **时期标签**（每条标签中必带其一，写小说时用于卡时间线）：
  - `#前期` ＝ 孤高锐利期（独唱歌姬～乐队结成初期，唯技术至上、急躁功利）
  - `#中期` ＝ 磨合与职业化期（All Fes 前后～出道，锐利中开始软化）
  - `#失意期` ＝ All Fes 受挫后动摇、自认不足、回到初心
  - `#后期` ＝ 豁达期（毕业后～正式踏入职业圈，看得见人、被夸会脸红、能说出「开心」）
- **标签用法**：可叠加检索，例如 `#莉莎`＝对莉莎的全部台词；`#猫`＝猫相关；`#金句`＝适合做标题或卷首引言的句子。
- **出处格式**：`卡面ID 2464《今の私たちの音楽》【第1篇】特训前《らしさ》`（日文篇名保留日文、中文篇名保留中文，与源文件分节头一致）。
