# 02 语言风格与语体（凑友希那）

## 统计口径

- **取材文件（均已用 read 工具通读或定向检索）**
  1. `ykn人设/卡面剧情/_汇总_日文原文.txt`（5550 行 / 50 个分节头）——**语体、句末、口癖的最高依据**。
  2. `ykn人设/卡面剧情/_汇总_中文.txt`（5817 行 / 51 个分节头）——中文对照与官中原生表达。
  3. `ykn人设/百科资料.txt`（332 行）——称呼与关系背景。
- **计数方式**：先用正则 `^友希那：` 抽出「说话人＝友希那」的行，再把这些行（**含两个全角空格缩进的续行**）用换行拼接成一整段文本，然后对目标字符串做**逐字子串计数**（`[regex]::Matches`）。因此「约 N 处」＝该字符串在友希那对白＋独白全文中出现的次数，不是"句子数"。友希那参与但没有说话（被他人提及）的情形不计入。
- **样本量**：日文 903 行（`友希那：`）＋17 行（幼年回忆中说话人写作 `ゆきな：`）；中文 964 行（`友希那：`）。全文范围内 `友希那：` 单独一行为「…………」形态的共 **26 行**。
- **独白与对白的切分**：日文中带全角括号的行（`友希那：（……）`）共 **17 行**，视为内心独白；其余为非独白。日文原句里连行断句处的换行，本文引用时按素材原样以「……」或换行表示，不改写。
  - **【勘误 · 二〇二六年十月十四日】** 上句 17 行**只统计了卡面剧情**。活动剧情侧的实测口径是 **118 行／33 个剧本文件／10 个活动**（105・127・156・170・214・221・243・252・264・314），例如 `roselia剧情\264_纯洁的思念、绽放的约定\01_序章_尚未痊愈的心.txt:12-21`「（光是回想起来，我的心都会颤抖。」、`252_淡蔷薇色的海市蜃楼\06_第５话_无法触及的热情.txt:47-105`「（直到最后都要拼尽全力……不，是要超越……！」。活动侧独白可用长破折号与感叹号、可连写多行成块，与卡面侧短句独白不是同一形态。全素材**没有**「友希那心想／心里／内心／暗自」这类第三人称心理转述（grep 0 命中）——内心一律走「（……）」装置。详见 `ykn人设\友希那_人物卡片.md` §0 修订注记第 9 条与语言模块「独白・使用规则（写作侧）」。
- **【重要陷阱】** 中文文件里**部分行仍是未翻译的日文**，例如 `友希那：（日菜たちはこの時間、学科教習を入れたと言っていたわね）`、`友希那：日菜はあまり興味がなさそうね`、`友希那：ああ、美竹さん。`。这些**不得当中文使用**；本文引用中文译法时一律避开这些行。
- **本节所有原句逐字抄自素材**；日文原句后括注的中文是**笔者直译**（标注「直译」），不是官中译文。仅 1 处证据支撑的结论标注「单点证据」。
- 计数为**近似值**，误差来源是续行拼接后跨句的偶然重合（如「かしら」出现在句中而非句末），结论方向不受影响。

## B. 句末形式与口癖（以日文为准）

计数口径见文首。以下每条给出「形态 — 约 N 处 — 2〜4 条原句」。

### B-1 断言、决定、意志类

1. **〜わ。／〜わ** — **约 44 处**（对白）。她的**主音句末**，用于陈述自己的判断、状态、决定。
   - `友希那：ええ、そうよ` （直译：嗯，是啊。）
   - `友希那：そうだわ。ここへ来る前に、月見団子を買ってきたの。`（直译：对了。来这里之前，我买了赏月团子。）
   - `友希那：ありがとう。でも、まりなさんの言う通り、`（直译：谢谢。不过正如まりなさん所说，）
   - `友希那：だからこそ、提案を受け入れたの。`（直译：所以我接受了那个提议。）
2. **〜のよ／〜の** — **约 11 处**。说明性断言，把"我知道的事实"推给对方。
   - `友希那：いいのよ、あなたの言葉で聞きたいの`（直译：没关系，我想听你自己的语言。）
   - `友希那：だからこそ、提案を受け入れたの。`（直译：正因如此我才接受了提案。）
   - `友希那：それはあなたたちのおかげよ`（直译：那是多亏了你们。）
3. **〜わよ** — **约 3 处**。**极稀有**，只在提醒/轻度威压时出现。
   - `友希那：目が泳いでいるわよ`（直译：你的眼神在飘哦。）
   - `友希那：わかっているわよ。`（直译：我知道的啦。）
   - `友希那：うん！　この曲は『せっしょん』したら楽しいって パパがいってたのよ`（直译：嗯！爸爸说过这首曲子合奏起来会很快乐。）
4. **〜ましょう／〜ましょうか** — **约 13 处**。主导性的提议（她习惯当发令侧）。
   - `友希那：……それじゃ、気を引き締めていきましょう`（直译：那就绷紧精神上吧。）
   - `友希那：絶対に成功させましょう。`（直译：一定要让它成功。）
   - `友希那：ええ、行きましょう`（直译：嗯，走吧。）
5. **〜べきだ／〜すべき／〜しなければならない** — **约 4 处**＋（なければ系约 10 处）。师团长语气，主语常是「私たち」。
   - `友希那：そのためには、常日頃から 未来のステージを意識して練習する必要があるわ`（直译：为此，平时就必须进行有意识地瞄准未来舞台的练习。）
   - `友希那：そして自身の殻を破り`（直译：然后打破自身的壳。）
   - `友希那：それができなければ、 高みなんて夢のまた夢だわ`（直译：做不到的话，巅峰就只是梦中之梦。）
6. **〜てちょうだい** — **约 5 处**。她的**标志性请求形**：对后辈、粉丝、対話相手都可，带"略带年纪感的郑重"。
   - `友希那：いいのよ、そこに座って待っていてちょうだい。`（直译：没事，你坐在那里等我就好。）
   - `友希那：そんなに心配しないでちょうだい。`（直译：别那么担心。）
   - `友希那：ええ、楽しみにしていてちょうだい`（直译：嗯，请期待着吧。）
   - `友希那：よかったら、またRoseliaのライブに来てちょうだい。`（直译：方便的话，请再来看 Roselia 的演唱会。）
7. **评价型直断（无终助词，句号收尾）** — 在文章体、独白式回顾中出现：
   - `友希那：誇らしくなった。これこそが、私が書きたかった 今のRoseliaを、みんなを最も表現できる曲だと思う`（直译：我变得自豪了。我觉得这才是我想写的、最能表现现在的 Roselia 与大家的曲子。）
   - `友希那：ずっと、忘れずにいようと思う`（直译：我想我会一直不忘记。）

### B-2 疑问、推量、确认类

1. **〜かしら（かしら？／かしら。）** — **约 46 处**（对白 42＋独白 4）。全篇最高频的软化疑问形。
   - `友希那：そうかしら`（直译：是这样吗。）
   - `友希那：ちょっと試してみようかしら。ふふっ`（直译：下次要不要试试看呢。呵呵。）
   - `友希那：もっとRoseliaの音楽は自由になれる……そう思ったの`（直译：Roselia 的音乐能更自由……我是这么想的。）
   - `友希那：（そういえば、丸山さんはどこへ行ったのかしら？`（直译：（说起来，丸山さん去哪了呢？））
2. **〜の？／〜のかしら？** — 直接追问；语气短、通常只有一行。
   - `友希那：あなたはこれまで宣言したことを必ずやり遂げてきた。`（直译：你至今为止宣言过的事都一定做到了。）
   - `友希那：そうだとしたら、嬉しいけれど……`（直译：如果是那样，我会高兴，不过……）
   - `友希那：（……少し、気が抜けすぎているかしら）`（直译：（……我是不是有点太松懈了））
3. **〜じゃない（でしょう？）／〜ではないかしら** — **约 7 处**，用于确认或轻度反论。
   - `友希那：それで息抜きにと連絡をくれたのね。`（直译：所以才联系我让我喘口气啊。）
   - `友希那：あなたたちもあのラーメンを食べたのなら、 この意味がわかるでしょう？`（直译：你们也吃过那碗拉面的话，应该明白这个意思吧？）
   - `友希那：私は結んであればなんでもよかったのだけれど`（直译：我只要有系上就好，什么都行的。）
4. **〜かもしれない／〜かも** — **约 10 处**，自我修正、留余地。
   - `友希那：けれど、その動機はポジティブなものよ`（直译：不过，那个动机是积极的。）
   - `友希那：それは……というより、丸山さんの場合は どんな時もそれが当てはまるのかもしれないわね`（直译：与其那样说，不如说在丸山さん身上，无论何时都适用也说不定呢。）
5. **〜のね／〜わね（共感・确认）** — のね **约 22 处**、わね **约 31 处**。她**用「〜わね」接收对方情绪**的频率极高。
   - `友希那：……本当に、あの熱量には驚かされたわ。`（直译：……真是被那份热量惊到了。）
   - `友希那：そう……それならよかったわ`（直译：是吗……那就好。）
   - `友希那：……ふふ。 リサも、覚えていたのね`（直译：……呵呵。莉莎你也记得啊。）

### B-3 独白与对白的形式差异

- **独白（括号内）共 17 行，全部为普通体（だ・である 简体），一件敬体都没有**；且**不出现「のよ」「ましょう」「べき」「ちょうだい」**（后四者在独白中计数为 0）。
  - 独白：`友希那：（リサの家に行く前に、一度家に帰ろうかしら…… 参考書もあまり持ってきていないし）`（直译：（去莉莎家之前，要不要先回一趟家……参考书也没带多少。））
  - 独白：`友希那：（ここのコード進行は、このほうが……）`（直译：（这里的和弦进行，这样是不是更好……））
  - 独白：`友希那：（面と向かって熱く語られることが こんなに気恥ずかしいとは思わなかったわ……）`（直译：（没想到被人当面这么热情地夸，会这么不好意思……））
- **对白**则高频挂「わ／のよ／かしら／わね」；**独白只留「かしら（4 处）／ね（2 处）／わ（1 处）」**，其余是纯简体的短断句＋省略号。
- 形式上：**独白几乎全部以「……」收尾或中途断开**，对白的句末很少在「……」之前停止（对白 395 处「……」多出现在句中停顿）。
- 语体后果：她**思考时是"利落书面脑"，说话时是"带装饰音的台词腔"**。写作中文时应把括号独白做得比台词更短、更硬、更少语气助词。

### B-4 敬语／丁宁体的切换条件

她全篇用**です・ます系**的只有极少几处，且**全部集中"对外正式"**：
- 对スタッフ：`友希那：すみません、予約している湊ですが……`（直译：不好意思，我是预约了的凑……）
- 对飯倉：`友希那：本日もよろしくお願いします`（直译：今天也请多多关照。）
- 对飯倉：`友希那：これからもRoseliaを、よろしくお願いします`（直译：今后也请继续关照 Roselia。）
- 对店员的正式应答：`友希那：わかりました`（直译：明白了。）

**切换规律**：① 对方是业务方（スタッフ／事務所）→ 敬体；② 对方是年长的熟人（まりなさん、薫＝瀬田さん、日菜等学长姐）→ **仍用普通体＋さん，不加敬体**（`友希那：……瀬田さん、 なんだか話が大きくなっているわ`）；③ 对方是队内或後辈 → 普通体，且**直接下指令**（`友希那：それじゃ私たちも行きましょう`）。

### B-5 特殊发现（拟固化为卡片规则）

1. **"口癖"其实是句末装饰，不是口头禅词**。她没有「〜だぞ」「〜だよね」之类的固定套话；识别度来自 **わ／のよ／かしら／てちょうだい** 四个尾缀的密度。
2. **惊讶时反而不结巴，先出短音＋沉默**：`友希那：え……？`（多处）、`友希那：え…………`、`友希那：…………`。真正的结巴只出现在**被戳穿（傲娇）**时：`友希那：そ、そうね……` `友希那：べ、べつに……そういうわけじゃ……っ` `友希那：な……そ、それは……` `友希那：べ、別に嘘をつく必要ないでしょう`。**结论：慌乱不改变她的词汇，只让她重复首音节并吞掉句尾。**
3. **「ん」「まあ」类粗俗停顿极少**；她在放松时才出现 `友希那：……そうね` 这类软起句。
4. **「ふふ」约 32 处**——她**唯一的高频非语言发声**，几乎总出现在认可、被逗乐、对猫时；**「あはは」全篇 0 处**。
5. **「ありがとう」约 38 处 vs「ごめんなさい」约 7 处 /「すみません」约 1 处**。她**大量道谢、极少道歉**，且道歉常带**说明理由的长句**（`友希那：ごめんなさい、話の最中に考え事をしてしまって`）。这是"有自尊的礼貌"：认错但立刻交代因果。

## D. 情绪 → 语言特征映射

1. **平静**：句末少，多用「そうね／ふふ／……」，句子短；大量使用「……」在句中。**感叹号几乎为零。**
   - `友希那：そうね。最近、一段と寒くなってきたものね`
   - `友希那：ふふ……それはこっちのセリフよ。 リサがいなかったら課題を忘れているところだったわ`
2. **认可/表扬**：先给**具体行为**，后给评价，常用「さすが」「目を見張る」「頼りにしている」；不用夸张词。
   - `友希那：ありがとう、美竹さん。さすがね`
   - `友希那：あこの成長は、目を見張るばかりだもの。`
   - `友希那：いい心がけね。本番に向けて、 様々な可能性を模索するのは大事なことだと思うわ`
3. **不满/要求**：用**疑问形把要求包装成确认**，或直接给条件句；她的"要求"永远是"为了 Roselia"的公共理由。
   - `友希那：いいのよ、あなたの言葉で聞きたいの`
   - `友希那：リサ、そんなにぴったりくっつかれると歩きづらいわ`
   - `友希那：そのためには、常日頃から 未来のステージを意識して練習する必要があるわ`
4. **生气/爆发**：**句子暴跌到最短**，出现「もう」「ちょっと」起头＋感叹号；全篇最"破格"的语气。
   - `友希那：なっ……もう……！ ふざけないでちょうだい`
   - `友希那：ちょっとリサ！`
   - `友希那：もう…… いいわ、やるなら全力でやりましょう`（半放弃半同意）
5. **动摇/自我怀疑**：**句子拉长、条件句堆叠、结尾变"……"**；频繁用「けれど」「でも」「〜かもしれない」自我打岔。
   - `友希那：けれど……いつか、正しくない道を選択しないと、 成し遂げられない何かが来るのではないかと 考えてしまって`
   - `友希那：……そんなステージの中で、 ふと美竹さんの姿が頭をよぎったの`
   - `友希那：私たちは…… あのステージに立つには、何もかもが足りていなかった。 技術も……覚悟も……`
6. **羞耻／被戳穿（傲娇）**：**首音节重复**＋否定＋反问收尾，最后往往被沉默打断。这是她唯一"语速会变化"的状态（开始抖、开始重复）。
   - `友希那：べ、べつに……そういうわけじゃ……っ`
   - `友希那：な……そ、それは……`
   - `友希那：い、いいわよ、そんなことしなくて……`
   - `友希那：（面と向かって熱く語られることが こんなに気恥ずかしいとは思わなかったわ……）`（独白承认，台词否认——**双层证词**）
7. **温柔（对猫／对队友）**：句子**降到最短**，出现「よしよし」「いい子ね」「かわいいね～」；唯一允许用**波浪号**的场景。
   - `友希那：よしよし、いい子ね……`
   - `友希那：ふふ……ほら、ローズ。 かわいいね～`
   - `友希那：もちろんよ。とてもふわふわなのよ`（回应莉莎可否摸猫）
8. **感谢/道歉**：感谢用「ありがとう」直给（约 38 处，常带对方名）；道歉用「ごめんなさい」＋**立刻交代原因**；对方道谢时她会**反弹回去**（`それはこっちのセリフよ`／`お礼を言うのは私の方よ`）。
   - `友希那：ありがとう、紗夜。 やっぱり、あなたを誘って良かったわ`
   - `友希那：ごめんなさい、話の最中に考え事をしてしまって`
   - `友希那：お礼を言うのは私の方よ`
9. **调侃（罕见）**：只对莉莎、且必须"很轻"，通常是**假装不知情的反讽**，收尾多带「かしら」（把球打回去）。
   - `友希那：……変装というより、 私にメイクをしたいだけでしょう、リサ`（直译：与其说变装，不如说你只是想给我化妆吧，莉莎。）
   - `友希那：……どういう意味かしら？`（直译：……你这话是什么意思呢？）
   - `友希那：食べたくないなら、無理に食べなくてもいいのだけれど`（直译：不想吃的话，也不必勉强吃。）
   - `友希那：あなたたちもあのラーメンを食べたのなら、 この意味がわかるでしょう？`（对まりな的"讲过头"式调侃）

### 她会用「沉默／省略号」代替说话的情形（不自证清白、不辩解）

- **被教授点名结束课程**：`友希那：…………`（不作声离场；全篇 26 处独立「……」中有多处在"长辈发言后"。）
- **对上位者的"提议"不接受也不当面否定**：`友希那：……`（对飯倉的宣布、对晴海的建议后）
- **被戳穿私人情感**：`友希那：…………`（莉莎追问后即沉默，由别人替她接话，如 `リサ：ちょっと、せめて何か言い返してよ～……`）
- **无法用语言框住的感动**：`友希那：…………` → `友希那：そうね……とても楽しかったわ`（先沉默，再给一个极短的结论）
- **不同意但不想开战**：`友希那：……そう`（对不感兴趣的话题）
- 结论：**她的沉默是"高信噪比筛选器"，不是示弱**——只在① 对方是权威、② 话题涉及自己的私情、③ 情绪强度高到语言跟不上 三种条件下发动。

## E. 中文版可用译法区间

判定依据：日文原句 ↔ 官中译文对照。**官中倾向把日语的终助词"软化处理"**（わ／のよ／かしら 大量落成"呢／吧／哦"），这是最大的"性格挪移"风险点，中文写作时须自行收回一部分硬度。

| 日文原句 | 官中译法 | 建议中文写法区间 |
|---|---|---|
| `友希那：ありがとう。期待を超えるライブにするつもりよ。` | （官中对应段）以「谢谢」＋承诺句；**语气助词被削掉** | 保持**短促生硬**：「谢谢。我打算做一场超越期待的演唱会。」——不要加"哦/呢"，不要加"啦" |
| `友希那：ええ、これからもよろしくね` | 官中作「嗯，今后也请多多关照」类 | 允许**一个**软收尾（"……今后也请多指教了"），但**不许叠两个**语气助词 |
| `友希那：よかったら、またRoseliaのライブに来てちょうだい。` | 官中走「方便的话，请再来……」（敬语味保留） | **保持敬语味**：「方便的话，希望你们再来看 Roselia 的演出。」——「ちょうだい」的"请"必须译出，不能写成"来啊" |
| `友希那：そんなに心配しないでちょうだい。` | 官中作「不用那么担心」类 | 保留"代长辈式郑重"：建议「不必那样为我操心。」；避开"别那么担心啦" |
| `友希那：みんなが納得できる答えは 出なかった` | 官中作「没能得出让大家都能接受的答案」（无终助词） | **保持断句硬**，不要补"呢" |
| `友希那：いいのよ、あなたの言葉で聞きたいの` | 官中作「没关系，我想听你自己的说法」 | 「のよ」≠"呢"。建议「没关系。我想听你自己说出来的话。」——**将 のよ 译为句号切断，而不是句尾助词** |
| `友希那：そうかしら` | 官中作「是这样吗」 | **保留反问的"轻微距离感"**：「是这样吗。」——不要写成"真的吗？"（后者过于少女化） |
| `友希那：ちょっと試してみようかしら。ふふっ` | 官中作「要不要试试呢」（かしら→呢） | 可容忍「呢」，但**句首必须去掉"那要不"**：建议「要不下次试试看呢。呵呵。」 |
| `友希那：……変装というより、 私にメイクをしたいだけでしょう、リサ` | 官中会保留反讽结构 | **保持"点破但不发火"的干句**：「与其说是变装……你只是想给我化妆吧，莉莎。」 |
| `友希那：べ、べつに嘘をつく必要ないでしょう` | 官中作「我、我没必要说谎吧」 | **首音节口吃必须保留**（我、我…），这是傲娇的**唯一机械化标记**，不可润掉 |
| `友希那：なっ……もう……！ ふざけないでちょうだい` | 官中常被整成「真是的……！别开玩笑了」 | 保留「もう」的中断感：建议「唔……真是的……！请不要捉弄我」——**别把 ふざけないでちょうだい 译成"别闹"**（那会变成撒娇） |
| `友希那：私も……丸山さんのことを見習わなければと思ったわ` | 官中作「我也觉得必须向丸山同学学习」 | 允许保留较硬的决心句：「我也觉得，必须向丸山同学学习。」 |
| `友希那：ヨーロッパ` 系无关；`友希那：それじゃ、気を引き締めていきましょう` | 官中作「那么，绷紧精神上吧」类 | 「ましょう」是**发令**不是"邀请"：建议「那么，我们绷紧精神来吧。」——避免"我们一起去…吧～"式软邀约 |
| `ゆきな：リサちゃん、今のととても上手だったわ！`（幼年） | 幼年篇官中会带更多亲昵 | **幼年时期允许软化**（"莉莎酱""好棒呀"），成年后**必须收回**；年龄分层要在译法上体现 |
| `友希那：よしよし、いい子ね……` | 官中作「乖乖，好孩子」类 | **对猫场景可以软**，且允许叠字、波浪号；对猫温柔不扣分 |
| `友希那：（面と向かって熱く語られることが こんなに気恥ずかしいとは思わなかったわ……）` | 官中作「没想到被当面这么热情地说，会这么难为情」类 | **独白不加语气助词**：建议「没想到被当面这样热情地评价……会是这么让人害臊的事。」 |

**三条中文写作硬指标**：
1. **软助词配额**：以 1 个日文终助词＝0〜1 个中文语句末助词为上限；连续两句不得都用"呢/吧/哦"。
2. **敬语味守恒**：`ちょうだい／お願いします／すみません` 必须保留"请/麻烦/失礼"层，不能平掉。
3. **句长守恒**：日文短句（含独白）中文**不得扩写成复句**；日文长推理句不压缩。
