剧情 txt 格式
-------------
每份文件开头是卡面元信息（卡面ID / 卡面名 / 日文原名 / 稀有度 / 属性 / 实装日期 / 资源名 / 卡面图 / 剧情篇数），
之后按「第1篇 特训前」「第2篇 特训后（回忆）」分段，正文每行一句台词：

    友希那：……莉莎？嗯，请进
    （旁白）某段没有角色名的叙述
    莉莎：呀嚯~☆
    　　我在下面叫过你，看你没反应，
    　　就跟阿姨说了声直接上来了

多行台词的第二行起以两个全角空格缩进；角色名后为全角冒号。

数据说明 / 已知缺口
-------------------
1. 「无剧情」判定与 Bestdori 一致：卡面页面的 Episodes 栏显示 “Not available” 的，都在本次跳过之列
   （Hololive 联动限定卡 1882、多数活动报酬 2★/3★ 卡、bilibili/纪念卡等）。
2. 卡面 ID 2536、2492 的官中文本尚未上架 CN 服，中文文件里已附日文原文并标注
   “（该篇暂无官方简体中文文本，以下为日文原文）”。
3. 15 张卡面只有一张卡面图（不可特训，Bestdori 侧只有 card_normal.png 或 card_after_training.png 之一）；
   缺失的另一半在 Bestdori 上同样不存在，卡面清单里已如实列出实际抓到的文件名。
4. 卡面名优先取简体中文；无简中时依次回退繁体中文 → 英文 → 日文。

重新运行 / 改阈值
-----------------
需要 Node.js（可用 DSH 自带运行时）：
    node "抓取脚本/抓取卡面与剧情.mjs"
脚本内 MIN_ID 控制卡面 ID 下界（默认 1217，取 > MIN_ID）。图片已存在的会跳过，
因此重复运行只会补缺。若图片被 Bestdori 以 200 + SPA 页面兜底（伪 PNG），
脚本会按 jp → cn → en → tw → kr 依次换区重试并做 PNG 魔数校验。
「修复图片并重建清单.mjs」用于图片校验收尾与重建 卡面清单.txt / _index.json。
